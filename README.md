# Cubit.Tools

Free, fast and private online tools: converters, calculators, countdowns and password generators. Every tool runs in the browser and nothing you enter is stored.

## How the site works

- **Content lives in a Google Sheet.** Each row is one tool (Slug, Category, H1_Title, Meta_Title, Meta_Desc, Intro_Text, Widget_Type, Config_JSON, Data_List, SEO_Body, plus the optional Short_Desc and Featured columns).
- **`build_site.py` turns the Sheet into static HTML.** It writes every tool page, every category page, the homepage, `sitemap.xml` and the data files in `data/`. Page text, breadcrumbs, the header, the Browse menu and the footer are all written into the HTML, so search engines see them without running JavaScript.
- **GitHub Actions runs the build** every night at midnight (`.github/workflows/deploy.yml`). To rebuild straight away, go to **Actions → Build Cubit.Tools Site → Run workflow**.
- **JavaScript only adds the interactive parts:** the tool itself (`js/widgets/`), search (`js/site-search.js`), the Browse menu toggle and the light/dark switch (`js/app.js`).

## Site address and launch

The site address is set in one place: `BASE_URL` near the top of `build_site.py`. The JavaScript works the address out for itself.

While `BASE_URL` is the temporary GitHub address, every page carries `<meta name="robots" content="noindex">` so search engines don't index the temporary copy. To launch on https://cubit.tools/:

1. Point the cubit.tools domain at the new host (or at GitHub Pages as a custom domain).
2. In `build_site.py`, change `BASE_URL` to `"https://cubit.tools/"` (the same as `LIVE_URL`).
3. Run the build. Every page, link, canonical tag and the sitemap switch to cubit.tools and the noindex tags are removed.

## Folders

| Path | What it is |
| --- | --- |
| `build_site.py` | The site builder |
| `components/header.html`, `components/footer.html` | Header and footer; edit these to change them on every page |
| `css/` | Styles (`style.css` main, `mega-nav.css` header and menu, `hub.css` category pages) |
| `js/app.js` | Page start-up: menu, search, theme switch, loads the right widget |
| `js/widgets/` | One file per tool type (unit converter, countdown, password generator, etc.) |
| `js/pools/` | Word lists used by the password generators |
| `data/` | Generated by the build; do not edit by hand |
| `about/`, `contact/`, `privacy/`, `terms/` | Hand-made pages (the build adds the header and footer to them) |

Everything else (tool and category folders, `index.html`, `sitemap.xml`) is generated and is overwritten on each build.
